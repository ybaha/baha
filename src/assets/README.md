# Vendored Cormorant font

`Cormorant-Variable.woff2` is the unsubsetted normal variable Cormorant font
(weights 300–700), served through `next/font/local`. Its SIL Open Font License
is included in `Cormorant-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/cormorant

Input: `Cormorant[wght].ttf`, version 4.000, SHA-256
`8f12cb21f05b61649192eaff13eeeb1b5619bc524feeae672fb916974259a076`.
Converted to WOFF2 with FontTools/Brotli, retaining the full glyph set and
variation axes. No font download or Python tooling is required to build the site.

Self-hosting preserves the font family and removes the Google stylesheet/font
fetch from clean builds, where the pinned Next/Turbopack Google-font loader failed.
